# 🛒 **Projeto_11_Dashboard_Ecommerce**

Um **Dashboard interativo** desenvolvido com **Streamlit**, **Pandas** e **Plotly**, utilizando um conjunto de dados fictício de vendas da Amazon.  
O objetivo é proporcionar uma visualização clara e dinâmica de métricas importantes relacionadas a países, fornecedores de crédito, tendências de vendas e comportamento geral do e-commerce.

---

## 🧠 **Situação-Problema**

Uma empresa de consultoria em e-commerce precisa analisar rapidamente o desempenho de vendas globais da Amazon em diferentes países.  
Os analistas enfrentam desafios ao tentar identificar:

- Quais países mais vendem  
- Tendências de vendas ao longo dos anos  
- Quais fornecedores de crédito têm maior participação no faturamento  
- Como o volume e o preço médio variam regionalmente

Para facilitar o trabalho da equipe, você deve desenvolver um **Dashboard interativo** que permita visualizar esses dados de forma simples, rápida e exploratória — sem a necessidade de escrever código.

Este é um dos projetos que seus alunos desenvolverão para praticar **Python**, **Streamlit** e **análise de dados aplicada**.

---

## 🎯 **Objetivo Educacional**

- Trabalhar manipulação de dados com **Pandas**  
- Criar visualizações com **Plotly Express**  
- Construir interfaces dinâmicas usando **Streamlit**  
- Reforçar análise exploratória com foco em negócios  
- Compreender como dashboards auxiliam em decisões estratégicas  
- Aplicar boas práticas de layout, filtros e storytelling de dados  

---

## ⚙️ **Funcionalidades Principais**

O dashboard apresenta:

### 📌 Indicadores (KPIs)
- **Total de Vendas**
- **Total de Países Selecionados**
- **Total de Empresas**
- **Quantidade de Provedores de Crédito**

### 📊 Visualizações (conforme print enviado)
- **Top 5 Países** segundo:
  - Quantidade de vendas  
  - Total vendido  
  - Preço máximo  
  - Preço mínimo  
  - Preço médio  
- **Linha do tempo** de vendas por ano para os países selecionados  
- **Ranking de Provedores de Crédito** por volume financeiro  
- **Mapa global** com distribuição de vendas (quando incluído no dataset)

### 🧩 Filtros Interativos
- Filtro múltiplo de países  
- Troca de métrica do ranking  
- Interface lateral intuitiva com menu vertical
